# Herramientas y Scripts Técnicos - Lotus Trading Academy

Bienvenido al repositorio oficial de código abierto de **Lotus Trading Academy**, una academia especializada en la formación técnica de trading e inversiones liderada por David Cánovas. 

Aquí compartimos herramientas útiles, scripts de automatización e indicadores en Pine Script para la comunidad de TradingView.
